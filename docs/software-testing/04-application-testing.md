## Web 与移动端测试 { #web-and-mobile-testing }

客户端测试既要验证业务功能，也要覆盖会话、展示、设备、网络和系统中断。Web 更关注浏览器与前后端交互，移动端还要处理安装、权限、功耗和生命周期。

### Web 测试

- **页面功能**：验证链接、按钮、表单、搜索、分页、上传下载和业务流程。
- **输入校验**：验证前端和服务端对必填、长度、格式、边界和非法字符的处理。
- **页面展示**：检查布局、文案、图片、字体、颜色、响应式和不同分辨率表现。
- **导航与链接**：检查菜单、面包屑、前进后退、刷新和失效链接。
- **会话管理**：验证 Cookie、Session、Token、登录超时、多端登录和退出登录。
- **权限控制**：不仅隐藏页面入口，还要验证直接访问 URL 或调用接口时的服务端鉴权。
- **浏览器行为**：验证刷新、重复提交、缓存、下载、弹窗和多标签页操作。
- **前后端交互**：使用浏览器开发者工具检查请求、响应、状态码、Console 错误和存储信息。
- **SEO 与可访问性**：面向公开网站时关注标题、语义结构、键盘操作和辅助技术支持。

### 移动端测试

- **安装与卸载**：验证首次安装、覆盖安装、卸载、重新安装和残留数据。
- **升级测试**：验证跨版本升级、数据迁移、配置兼容和失败回滚。
- **设备兼容**：覆盖不同品牌、系统版本、屏幕尺寸、分辨率和硬件能力。
- **网络测试**：验证 Wi-Fi、蜂窝网络、弱网、断网、切网、代理和网络恢复。
- **中断测试**：验证来电、短信、通知、锁屏、切后台、系统弹窗和进程被杀。
- **权限测试**：验证相机、相册、定位、麦克风等权限的允许、拒绝和再次询问。
- **手势与交互**：验证点击、滑动、长按、多点触控、旋转和返回操作。
- **资源与功耗**：关注 CPU、内存、流量、电量、发热、启动时间和安装包大小。
- **推送测试**：验证前台、后台、离线、点击跳转、重复推送和权限关闭。
- **数据安全**：检查本地存储、剪贴板、日志、截图和敏感信息展示。

## API 与服务集成测试 { #api-and-service-integration }

接口测试直接验证服务请求、响应、业务规则和依赖交互。除正常返回外，还应覆盖鉴权、幂等、超时、异常数据和契约兼容。

### 接口测试

- **接口测试**：绕过或弱化界面，直接验证服务之间请求、响应、数据和业务规则。
- **请求组成**：常见包括 URL、方法、路径参数、查询参数、请求头、Cookie 和请求体。
- **HTTP 方法**：常见有 GET、POST、PUT、PATCH、DELETE；具体语义以接口约定为准。
- **状态码**：验证状态码与业务结果匹配，并同时检查响应体，不能只看是否返回 200。
- **参数校验**：覆盖必填、类型、格式、长度、枚举、边界、空值、重复和未知字段。
- **响应校验**：检查状态码、字段、类型、结构、业务值、错误码、响应头和响应时间。
- **业务规则**：验证状态流转、数据计算、库存、金额、权限和上下游一致性。
- **鉴权与授权**：验证无凭证、凭证失效、越权、不同角色和资源归属。
- **幂等性**：同一请求重复执行时，系统结果应符合接口约定，尤其关注支付、下单和重试。
- **依赖与异常**：验证下游超时、失败、返回异常数据以及降级、重试和熔断行为。
- **契约测试**：验证服务提供者与消费者对接口结构和语义的约定保持兼容。
- **接口工具**：常见有 curl、Postman、Apifox、Swagger / OpenAPI 客户端和自动化测试框架。

## 数据库与数据一致性测试 { #database-and-data-consistency }

数据库测试验证数据、约束、事务和并发行为是否支撑业务规则。界面或接口显示正确并不代表底层数据一定完整、一致和可恢复。

### 数据库测试

- **数据正确性**：数据库中的值应与业务操作和计算结果一致。
- **数据完整性**：验证主键、外键、唯一、非空、默认值和检查约束。
- **数据一致性**：跨表、跨服务、缓存与数据库之间应保持业务一致。
- **CRUD**：验证数据新增、查询、修改和删除操作。
- **事务**：验证原子性、一致性、隔离性和持久性，以及提交、回滚和并发行为。
- **并发控制**：验证锁、隔离级别、丢失更新、脏读、不可重复读和幻读等风险。
- **存储过程与触发器**：检查输入、输出、异常处理、事务和副作用。
- **数据迁移**：验证字段映射、数量、精度、编码、关系、重复和遗漏。
- **备份恢复**：确认备份可用、恢复后数据完整，并满足恢复目标。
- **性能**：关注慢查询、索引、执行计划、连接池和大数据量下的表现。
- **SQL 安全**：验证参数化查询、最小权限和敏感数据保护，防止 SQL 注入。

## 常见业务功能测试模式 { #common-business-testing }

登录、支付、上传和定时任务等功能虽然业务不同，却共享边界、状态、权限、并发和恢复等测试视角。模式化检查可以提高分析速度，但仍需结合具体规则。

### 常见业务功能测试视角

**登录**

- 正确 / 错误账号密码、空值、长度和特殊字符。
- 验证码、连续失败锁定、记住登录、会话过期和退出。
- 多设备登录、密码修改后会话处理和暴力破解防护。

**注册**

- 必填、格式、唯一性、验证码、协议勾选和年龄限制。
- 重复注册、并发注册、激活链接过期和敏感信息保护。

**搜索**

- 精确 / 模糊搜索、多条件组合、大小写、空格和特殊字符。
- 无结果、排序、分页、搜索历史、超长关键字和大数据量性能。

**分页**

- 首页、末页、上一页、下一页、指定页和每页条数。
- 空数据、单页、最后一页不足、数据新增删除后的页码变化。

**文件上传**

- 文件类型、大小、数量、名称、重复文件和特殊字符。
- 空文件、损坏文件、伪造扩展名、病毒风险、中断与重试。

**文件下载**

- 文件内容、名称、格式、大小、权限、重复下载和中断恢复。
- 不存在文件、过期链接、越权下载和中文文件名。

**订单与支付**

- 金额、优惠、库存、运费、税费和精度计算。
- 重复提交、并发下单、超时、取消、退款和回调幂等。
- 支付成功但通知失败、支付失败但订单状态异常等一致性问题。

**权限**

- 不同角色的菜单、按钮、接口和数据范围。
- 未登录、权限变更、直接访问地址、参数篡改和水平 / 垂直越权。

**消息与通知**

- 触发条件、接收人、内容、模板、多语言和发送渠道。
- 重复、延迟、失败重试、退订和敏感信息泄露。

**定时任务**

- 执行时间、时区、重复执行、漏执行和补偿机制。
- 任务并发、执行超时、失败重试、幂等性和告警。
